## Descripción General
Desarrollo de una herramineta interna para gestionar una flota de furgonetas eléctricas, registro de vehículos, gestión de entregas y lógica de seguridad.

## Guía de Instalación
Para configurar el entorno sigue estos pasos:
1. **Clonar el repositorio:** `git clone https://github.com/barimah207/ecoroute.git`
2. **Crear el entorno virtual:**
   - Windows: `python -m venv venv
   - Linux/macOS: `python3 -m venv venv`
